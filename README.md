# UrbanThreads — Clothing E-commerce Mini Project

A responsive clothing store demo built with plain HTML, CSS and vanilla JavaScript.

## Run
1. Extract `UrbanThreads_Mini_Project.zip`.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Internet access is recommended for fashion product photos and Google Fonts. The cart and UI logic run locally.

## Features
- Clothing catalogue with Women, Men and Kids categories
- Search by product name, category, type or colour
- Filters: category, max price, size and colour
- Sort by featured, price, rating and name
- Add to bag, change quantities, remove items, favourites
- Automatic subtotal, shipping, discount and total calculations
- Coupon `STYLE10` gives 10% off the product subtotal
- Free shipping for subtotal of ₹999 or more; otherwise ₹79 shipping
- Checkout form with browser validation and simulated order confirmation
- Responsive layout for desktop and mobile

## Important
This is a front-end student project. It does not process payments, create real orders, or send customer details to a server.

Files: `index.html`, `style.css`, `script.js`, `README.md`.
